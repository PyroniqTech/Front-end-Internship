# 🧩 TaskGrid — Team Management System  

### 📘 Project Description  
TaskGrid is a simple yet powerful team management web application built using **HTML**, **CSS (Tailwind)**, and **JavaScript**.  
It allows users to **add, view, and manage teams**, as well as communicate through a **contact form**.  
The system is designed to demonstrate clean UI design, form validation, and dynamic interaction using vanilla JavaScript.  

---

### 🚀 Features  
- 🧑‍🤝‍🧑 **Team Management** — Create and view multiple teams dynamically.  
- 📨 **Contact Form** — Send messages with proper validation.  
- 🎨 **Responsive Design** — Fully optimized for desktop and mobile screens.  
- ⚙️ **Modal Functionality** — View team members in a clean modal popup.  
- ✅ **Form Validation** — Ensures user inputs are complete and valid before submission.
