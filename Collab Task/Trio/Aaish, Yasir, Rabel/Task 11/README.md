## 📝 Project Overview
**BlueCode** is a fully responsive **frontend-only web project** built for a **Tech & Software Agency**.  
It demonstrates modern UI/UX principles, responsive layouts, and clean code architecture using **HTML5**, **CSS3**, **Tailwind CSS**, **Bootstrap**, and **Vanilla JavaScript**.

The website contains **7 pages**, all sharing a consistent structure and design to ensure professional presentation and user-friendly navigation.

---

## 🎨 Features
- ✅ Fully responsive on all devices  
- ✅ Smooth scroll for anchor links  
- ✅ Minimal animations (fade-in effects)  
- ✅ Interactive elements (forms, modals, filters) using JS  
- ✅ SEO-friendly meta tags and structure  
- ✅ Clean, readable, and organized code
