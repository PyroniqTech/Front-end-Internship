# OpulenX - Luxury 3D Brand Landing Page

## Project Overview

A fully responsive, single-page landing page for OpulenX, a luxury 3D brand showcasing premium products and immersive experiences.

## Candidate Name

Rabel Sahad Gul

## Tech Stack Used

- HTML5
- CSS3 (Custom CSS + Tailwind CSS + Bootstrap 5)
- JavaScript (Vanilla ES6)

## Features Implemented

- Responsive design with mobile-first approach
- Smooth scrolling navigation
- Interactive product showcases with 3D hover effects
- Form validation for contact section
- SEO-optimized with proper meta tags
- Lazy loading implementation for images
- Cross-browser compatibility

## Instructions to Run

1. Download all files maintaining the folder structure
2. Open `index.html` in any modern web browser
3. No additional setup or dependencies required

## Sections Included

1. Hero Section - Brand showcase with call-to-action
2. Products Section - 3D product visuals with descriptions
3. About Section - Brand story and values
4. Gallery Section - Image showcase with 3D preview options
5. Contact Section - Contact form and company information
