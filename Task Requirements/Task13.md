# Pixel-Perfect Development — Requirements

- Rebuild the provided design (PSD/PDF/Figma) exactly in HTML/CSS.  
- Match spacing, typography, colors, and layout with pixel accuracy.  
- Use semantic HTML and clean, modular CSS.  
- Implement responsive layout with Flexbox/Grid.  
- Include correct hover, focus, and active states.  
- Use optimized images/SVGs.  
- Ensure basic accessibility (keyboard, alt text, focus).  
- Provide: HTML file, CSS files, assets folder, minimal JS if needed, and a README with notes.  
- Final output must be fully responsive, clean, and visually identical to the design.
