# 🍴 Restaurant Menu Page

## 🔹 Objective
Create a **responsive restaurant menu web page** where users can view food items by category such as *Starters, Main Course, Drinks,* and *Desserts*.

## 🔹 Features to Include

### 1️⃣ Header Section
- Restaurant name/logo  
- Navigation bar: **Home | Menu | Contact**

### 2️⃣ Menu Section
Display food items in a **grid/card layout**.  
Each item must include:
- Image  
- Name  
- Short description  
- Price  

### 3️⃣ Category Filter (JavaScript)
Filter food items dynamically using category buttons:
- **All | Starters | Main Course | Desserts | Drinks**  
When a button is clicked, only that category’s items appear.

### 4️⃣ Search Bar (Bonus)
- Allows users to type a dish name.  
- Filters and displays matching dishes automatically.  

### 5️⃣ Responsive Design
- Fully responsive for **mobile, tablet, and desktop**.  
- Navbar turns into a **hamburger icon** on mobile.  
- Menu items rearrange into single-column layout on smaller screens.

### 6️⃣ Footer
- Contact Information: Address, Phone, Email  
- Social Media Links: Facebook, Instagram, Twitter, etc.

## 🔹 Tech Stack
| Component | Technology |
|------------|-------------|
| Structure | HTML5 |
| Styling | CSS3 |
| Interactivity | JavaScript (Vanilla) |

## 🔹 Example Flow
1. Page loads → all menu items are displayed.  
2. User clicks **Desserts** → only desserts are visible.  
3. User searches **Pizza** → only pizza item(s) appear.  
4. On mobile → layout adapts to a single column for better readability.
