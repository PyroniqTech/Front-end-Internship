# Task 10 — OpulenX

Build a fully functional frontend-only business landing page for a 3D luxury brand named OpulenX.

Each candidate will work individually to deliver a complete, polished, and production-ready web app.

## Tech Stack

HTML5

CSS3 (Custom + Tailwind + Bootstrap hybrid)

JavaScript (Vanilla, ES6)

## Folder & File Structure
```
OpulenX/
├── index.html
├── style.css
├── script.js
├── images/
│   ├── logo.png
│   ├── product1.png
│   ├── product2.png
│   └── ...other assets
└── README.md
```
## Project Details

Type: 3D Luxury Brand Landing Page

Category: Business / Product Showcase

Pages: Single page (index.html)

Sections: 5 sections minimum:

1. Hero (brand showcase + CTA)

2. Products / Features (3D visuals + descriptions)

3. About Brand (story, values)

4. Gallery / Showcase (images, videos, 3D preview)

5. Contact / Footer (social links, form)

Navigation: Sticky, fully responsive, functional across all viewports

Footer: Address/Company Info, Copyright, Social Icons (Facebook, GitHub, LinkedIn, WhatsApp, Instagram)

## JavaScript Requirements

- Smooth scrolling navigation
- Interactive product showcase (3D rotation optional or hover effects)
- Form validation (Contact section)
- No commented or unused code
- Optimized and modular

## CSS Guidelines

- Hybrid: Tailwind + Bootstrap + Custom CSS
- Mobile-first, fully responsive
- Use utility classes from Tailwind + Bootstrap + minimal custom overrides
- Optimize all visual elements (lazy loading images, compressed assets)

## SEO & Meta Tags (Mandatory)

Include all 5 meta tags in index.html:

<title>OpulenX — Luxury 3D Brand Landing Page</title>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="OpulenX — Explore luxury products and immersive 3D experiences.">
<meta name="keywords" content="Luxury, 3D, Brand, OpulenX, Business, Landing Page">
<meta name="author" content="Candidate Name">

## Best Practices

- Lazy load all images (loading="lazy")
- Alt text for all images
- Use relative paths for assets
- Clean, readable indentation
- No console logs, no placeholders, no commented-out code
- Fully responsive and cross-browser compatible

## README.md Requirements

- Project Title: OpulenX
- Candidate Name
- Tech Stack Used
- Features Implemented
- Folder Structure Overview
- Instructions to Run (open index.html in browser)

## Final Goal

Deliver a professional-quality, single-page OpulenX landing page that is:

- Fully responsive
- SEO-ready
- Optimized for performance
- 3D/interactive ready
- Portfolio-worthy
