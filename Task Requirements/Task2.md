# 🛍️ Product Landing Page

## 🔹 Objective
Create a **landing page for a single product** (e.g., headphones, coffee maker, or a book) to highlight its features, pricing, and customer reviews with a modern responsive design.

## 🔹 Features to Include

### 1️⃣ Header
- Product logo or brand name  
- Navigation bar: **Home | Features | Reviews | Buy Now**

### 2️⃣ Hero Section
- Large product image  
- Catchy tagline or short description  
- Prominent **“Buy Now”** button  

### 3️⃣ Features Section
- 3–4 feature boxes showcasing main highlights  
- Each box includes an **icon + short text**  

### 4️⃣ Pricing Section
- Product price displayed clearly  
- Call-to-action button: **“Buy Now”**  

### 5️⃣ Reviews Section
- Customer review cards  
- Include **user name, image (optional), comment, and star rating**  

### 6️⃣ FAQ Section
- Accordion-style layout using **JavaScript toggle**  
- Expands/collapses answers on click  

### 7️⃣ Footer
- Social media links (Facebook, Instagram, YouTube, etc.)  
- Contact information: **email, phone, or address**

## 🔹 Tech Stack
| Component | Technology |
|------------|-------------|
| Structure | HTML5 |
| Styling | CSS3 |
| Interactivity | JavaScript (Vanilla) |

## 🔹 Example Flow
1. Page loads showing **Hero Section** with product and “Buy Now” button.  
2. User scrolls → sees product **features** and **pricing**.  
3. Reviews section shows user testimonials.  
4. FAQ expands with JavaScript toggle.  
5. Clicking “Buy Now” triggers a **JavaScript alert** (simulated purchase action).  
6. Footer remains accessible with **contact and social links**.
