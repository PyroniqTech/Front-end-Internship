# OpulenX

Developer : Osama Zia

## Tech Stack
- HTML5
- CSS3 (Bootstrap + Tailwind utilities + custom CSS)
- JavaScript (Vanilla ES6)

## Features Implemented
- Single-page responsive landing page with 5 sections: Hero, Products/Features, About, Gallery, Contact.
- Sticky navigation and smooth scrolling.
- Interactive product previews with 3D-like hover rotation effects.
- Contact form with client-side validation and accessible feedback.
- Lazy-loaded images and alt text for accessibility.
- Mobile-first responsive design and progressive animations.

## Instructions to Run
1. Place the `OpulenX` folder on a static host or local directory.
2. Open `index.html` in a modern browser.
3. The page is fully frontend-only; no backend required.
