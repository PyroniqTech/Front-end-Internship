# OpulenX — 3D Luxury Brand Landing Page

A modern, responsive, and interactive business landing page built for **OpulenX**, a 3D luxury brand that showcases elegant décor and digital art pieces.

## 🧩 Tech Stack
- **HTML5**
- **CSS3 (Custom + Tailwind + Bootstrap Hybrid)**
- **JavaScript (Vanilla ES6)**

## ✨ Features
- Responsive and accessible layout  
- Smooth scrolling navigation (JavaScript based)  
- Animated hero section  
- Product showcase with hover effects  
- Professional 3D image gallery  
- About and contact sections with form  
- Social media footer links  

## 📁 Folder Structure
OpulenX/
├── index.html
├── style.css
├── script.js
└── images/


## 🚀 How to Run
1. Clone or download the project.  
2. Open `index.html` in your browser.  
3. Explore all sections and animations.
